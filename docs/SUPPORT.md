## 自愿打赏

项目计划提供自愿支持入口。**当前尚未启用任何收款渠道**，也没有已确认的收款二维码或赞助账号。未来打赏将用于项目维护、平台测试和文档完善；它不改变开源许可证，也不表示购买受保护启动或某项服务保证。

GitHub 可以显示 **Sponsor** 按钮，链接 GitHub Sponsors、外部支持平台或维护者提供的公开收款页面。配置放在 `.github/FUNDING.yml`，必须等维护者确认真实渠道后再启用。[GitHub 官方说明](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/displaying-a-sponsor-button-in-your-repository)

GitHub Sponsors 可设置一次性或按月支持；收款资格取决于居住或运营地区和账号审核。应按当前官方名单确认资格，不能用仓库地址或界面语言判断。暂未支持的地区可以加入候补名单。[GitHub Sponsors 官方说明](https://docs.github.com/en/sponsors/getting-started-with-github-sponsors/about-github-sponsors)

只需要向维护者确认公开链接或已脱敏二维码。不要在 Issues、Pull Requests 或聊天中提供银行卡信息、支付密码、身份材料或后台凭据。仓库发布仍暂停，打赏入口也不会提前推送上线。

## Support in English

A Star, a reproducible issue, a translation review, documentation or a code contribution helps Envara grow. Financial support will be optional. **No payment channel is currently enabled.**

GitHub's Sponsor button can link to GitHub Sponsors, an external platform or a confirmed public support page. GitHub Sponsors supports one-time and monthly contributions; receiving funds requires eligibility in a supported region. A repository funding link does not establish an approved Sponsors account. See the official documentation linked above.

Future support will help with maintenance, platform testing and documentation. It does not change the open-source license or promise a particular feature or service outcome. Do not post payment credentials or identity documents. Publication remains paused until the maintainer authorizes it.
