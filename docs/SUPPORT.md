# 支持 Envara · Support Envara

Star、可复现的反馈、翻译校对、文档和代码贡献，都能帮助境舱继续完善。

- [给项目一个 Star](https://github.com/ink-scholar/Envara)
- [提交问题或建议](https://github.com/ink-scholar/Envara/issues)
- [参与贡献](../CONTRIBUTING.md)

支持完全自愿。**当前没有启用捐赠账号、二维码或收款渠道。** 如将来开放，会由维护者公布真实公开链接。支持不会改变开源许可证，也不代表购买某项服务保证。

A Star, reproducible issue, translation review, documentation or code contribution helps Envara. Financial support is optional; **no payment channel is currently enabled**. Any future channel will be announced by the maintainer and will not change the license or guarantee a service outcome.
