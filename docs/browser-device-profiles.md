# 浏览器设备档案与语言

设备档案放在创建/编辑境舱的 **高级设置 → 设备档案**。当前固定档案面向 CloakBrowser，并按当前宿主平台提供相应模板。其他内核继续使用原有配置。

- 新建的受支持环境默认使用本机平台的标准档案；旧环境显示“自定义（保留当前配置）”，不会被自动改写。
- 档案固定保存屏幕尺寸、像素比、浏览器可见的逻辑 CPU 线程数和内存值。重启、换节点、调整地区都复用这些值。
- 克隆保留设备规格，但仍按原有逻辑分配新的浏览器种子；导入导出保留档案版本。跨宿主平台的固定模板应明确转为自定义后再导入。
- 更改设备档案需要先停止环境的相关运行实例。切回自定义保留当前值，不会重置登录数据。

| 标准档案 | 屏幕 | 像素比 | 逻辑 CPU | 浏览器内存 |
| --- | --- | --- | --- | --- |
| macOS | 1440 × 900 | 2 | 8 | 8 GB |
| Windows | 1920 × 1080 | 1 | 8 | 8 GB |
| Linux | 1920 × 1080 | 1 | 8 | 8 GB |

这些是浏览器向网页呈现的设置，不是整台电脑的硬件规格。当前实机验收范围是 Apple Silicon macOS + 随包使用的 CloakBrowser；Windows/Linux 模板只有配置逻辑，仍需各自实机验收。

## 已知边界

当前 macOS 内核的 GPU 字符串覆盖和字体名单限制未通过实测，因此模板不包含它们，也不修改或删除宿主字体。浏览器仍可能暴露 Apple GPU 和本机可用中文字体。`screen.availHeight` 由内核/窗口环境决定，不能把它等同于保存的屏幕高度。

现有内核的默认 UA Chrome 版本与实际引擎版本存在差异，UA-CH 部分版本字段为空。本次设备字段验收不代表完整 UA、GPU、字体或所有浏览器指纹的一致性验收。

## 语言可以分层设置

**浏览器：** 使用境舱高级设置的语言，自动模式按网络地区推荐，也可手动固定，例如 `en-US` 或 `ms-MY`。浏览器语言、请求的 `Accept-Language` 与 `Intl` locale 可单独设置。网站仍可按账户、Cookie、页面路径或服务端规则显示其他语言；页面显示中文不一定是浏览器 locale 错误。

**终端与 Claude Code：** 子进程按同一境舱的请求语言选择宿主实际安装的 locale，并设置自己的 `LANG` 和 `LC_ALL`。缺少精确 locale 时，依次选择同语言的 UTF-8 locale、有效英语 UTF-8 或中性 locale；界面显示实际采用的语言与回退。比如这台测试 Mac 没有 `ms_MY.UTF-8`，不能把这个无效变量当作马来语已生效。配置只作用于自有子进程，不更改系统语言。

**附加软件：** 复用同一套有效子进程环境，但不同原生软件对语言变量的支持不同，不能据此宣称任意 GUI、系统语言 API、字体或硬件身份都已隔离。完整方案和可行性见[原生设备隔离研究](native-device-isolation-research.md)。

Envara 界面语言、浏览器语言、终端有效语言和宿主字体是不同层次；网络地区不代表某一种硬件或语言，更不代表账户安全结论。

## 0.5.4 本地验证

Apple Silicon macOS 打包版通过 8 项真实浏览器检查：默认档案、服务重启、从美国到马来西亚的认证离线代理夹具切换、手动语言覆盖、冲突拒绝、克隆种子更新、跨平台固定模板拒绝，以及自定义 DPR 1 / CPU 4 / 内存 4 参数。网页实际读到默认档案的 1440 × 900、DPR 2、8 线程和浏览器内存 8；HTTP `Accept-Language`、页面语言与 `Intl` locale 同步。测试结束后没有遗留自有浏览器进程。

这些测试使用本地认证夹具和真实内核，未验证真实账户登录、公共节点住宅属性或服务端账户判断。前端中/德文渲染与保存流程、9 种语言文案、打包资源一致性均已检查。完整 Node 回归共 1763 项，1761 通过，2 项可选真实 Chromium 测试跳过，0 失败；本轮另外运行了上述打包浏览器验收和 Go DPR 参数测试。

同一 0.5.4 包通过 16 项 Claude 终端验收，包括手动启动 CLI、所选浏览器 MCP 操作、换路拒绝、故障处理与清理。真实 PTY 中 `en-PH` 使用 `en_PH.UTF-8`，`ms-MY` 明示回退到 `en_US.UTF-8`；`LANG` 与 `LC_ALL` 一致，libc 字符集为 UTF-8，中文和 emoji 输出完整。结束后自有 PTY 残留为 0；未进行真实账号登录或模型请求。
