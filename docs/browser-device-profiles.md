# 浏览器设备档案与语言

本文描述 Envara 1.0.3 的当前实现，发布目标为 macOS arm64；本次制品核验范围见[1.0.3 发布验证](verification.md#103-发布验证)，维护者付款实测保留在 1.0.1 记录中。三内核随机身份与资料迁移的历史实测归属已发布 0.5.24 的基线，0.5.25 的功能范围另行标注；旧版本结果不构成 1.0.3 安装包验收，各版本的实测范围见[验证说明](verification.md)。基本设置选择名称、网络和内核；设备覆盖与手动参数位于 **高级设置**。

## 自动与固定档案

三个 provider 的新环境在创建时生成并保存身份：Chromium provider 保存种子及一组相容的设备参数，Camoufox 保存按目标 OS 生成的完整结构化模板与其支持的噪声参数。重新打开复用已保存身份，不在启动时重新随机。有限模板不保证每个硬件字段唯一，也不表示所有浏览器信号都已随机化。

复制创建新身份，保留显式设备约束，不复制原浏览资料；导入保留已有身份配置，不把它作为新环境重新生成。旧环境保留既有档案、种子、手动设置和浏览资料，不进行隐式迁移。旧 BrowseForge Chromium 档案若种子为零、依赖原 profile ID 派生身份，导入后新 ID 可能改变派生结果，不能承诺完整身份一致；正常新生成身份及已保存的非零旧种子在已测范围内保留。

| Provider | 0.5.24 基线真实内核观测与边界 |
| --- | --- |
| CloakBrowser | 原生 Canvas 像素读回可随身份变化；该次验证的 `toDataURL()` 与字体测量未观察到相应变化，不能将这些表面也宣称为已随机化 |
| BrowseForge Chromium Alpha | 新生成身份接入原生 Canvas 随机参数；默认不启用音频噪声。该版本上游音频噪声会改变音频数组的处理行为，不能将其作为默认功能承诺 |
| Camoufox | 按 OS 抽取完整官方生成模板，保存字体间距与 Canvas 参数；受控验证覆盖新环境差异、同环境重开稳定、复制更新及配置导入保持。数据来源与许可见[模板说明](../third_party/browseforge/internal/profile/camoufox-data/README.md) |

历史 0.5.25 版本的固定档案只映射到 CloakBrowser，并要求模板匹配宿主平台；1.0.0 沿用这些规格，并扩展到下节列出的 provider：

| 模板 | 屏幕 | 像素比 | 逻辑线程 | 网页可见内存 |
| --- | --- | --- | --- | --- |
| macOS | 1440 × 900 | 2 | 8 | 8 GB |
| Windows | 1920 × 1080 | 1 | 8 | 8 GB |
| Linux | 1920 × 1080 | 1 | 8 | 8 GB |

固定档案在重启、换节点与地区变更后复用规格。克隆保留规格并分配新种子；导入导出保留档案标识。跨宿主模板需明确改为自定义后再导入。修改前需停止相关实例，切换自定义不清理登录数据。

上述值只是网页可见参数。Windows/Linux 模板的配置逻辑不构成相应平台实机验收，浏览器档案不虚拟化整机硬件。

### Camoufox 与 BrowseForge Chromium 固定模板（1.0.0 实现）

1.0.0 将上述固定模板扩展到另外两个 provider，仍由用户在高级设置中明确选择。字段按实际内核映射：

| Provider | 固定模板映射 | 保留的边界 |
| --- | --- | --- |
| BrowseForge Chromium | 屏幕宽高、像素比、逻辑线程、网页可见内存 | 可用屏幕区域、窗口和 viewport 由原生 persona 派生；GPU、字体与内核身份不由此模板替换 |
| Camoufox | 屏幕和可用区域、外层窗口尺寸与位置、像素比、逻辑线程 | Firefox 没有对应的网页内存参数，不映射 RAM；内层 viewport 保留原生行为。外层窗口尺寸固定，不能承诺随用户拖动更新 |

仅在新环境明确选择固定模板，或旧环境明确切换模板时应用相应字段。普通编辑、保留同一模板的保存以及导入不会重新套用几何参数；旧自定义和已导入身份继续保留。固定标签的导入必须具备一致的完整字段，缺失或冲突时拒绝，不补造另一套身份。

复制保留选定的固定规格并生成新身份；导入保留导出的指纹、来源记录和种子。Camoufox 的模板转换还核对已保存的 OS 身份：旧身份跨 OS，或包含 GPU/字体但无法确认来源时，要求保留自定义配置，不能只更换平台标签。以上是 1.0.0 的实现规则，最终安装包中的真实内核与窗口行为仍需验证；已完成的实测范围见[验证说明](verification.md)。

## UA、GPU 与字体

UA 必须与实际运行的内核家族及版本对齐；验证同时核对页面、worker、HTTP 请求头，以及支持 UA-CH 的 Chromium 字段。Firefox 没有 Chromium 的 UA-CH 接口。CloakBrowser 使用实际内核的 UA/Client Hints，不套用其他 provider 的版本覆盖。完整 UA 可以减熵到主版本，UA-CH 的完整版本需按其实际字段判断；不能把二者字符串必须完全相同作为一致性标准，也不能通过改写 UA 把旧内核当作新内核。

固定设备档案不覆盖 GPU 字符串或字体名单，也不修改宿主字体；网页仍可能看到宿主 GPU 和可用字体。Camoufox 的随机身份模板另包含按 OS 配套的完整 WebGL 样本和字体配置，显式固定设备规格保留其相容身份，但不模拟一台确定型号的物理电脑。`screen.availHeight` 等可见参数仍需按 provider 与窗口环境验收。语言、屏幕参数或 UA 校验通过不代表完整指纹一致，也不保证第三方评分或挑战放行。

WebRTC 另行验收：两个 Chromium provider 已配置禁用非代理 UDP 的策略，但尚无有效正对照证明防泄漏效力；Camoufox 的 WebRTC 防泄漏效力也未验收。接口可用或没有候选地址均不足以证明已通过。

## WebSocket 追踪规则（1.0.0 实现）

0.5.25 的追踪拦截接入覆盖第三方 HTTP(S) 请求；1.0.0 新增页面和 frame 发起的 WS/WSS 连接规则，沿用关闭、标准、严格模式及第一方/明确服务根豁免。普通网站连接仍应使用所选代理；规则命中的第三方追踪连接在连接目标之前被拒绝。

| Provider | WebSocket 接入 | 规则与计数边界 |
| --- | --- | --- |
| BrowseForge Chromium | Playwright `RouteWebSocket` | Go 后端处理内建域名及支持的 EasyPrivacy `$websocket` 规则，提供拦截计数 |
| CloakBrowser | 页面与 frame 的 WebSocket 构造器适配 | 使用内建分级域名；拦截计数不可用，不显示为零次拦截 |
| Camoufox | 应用自有临时 Firefox MV2 扩展，通过 `webRequest` / `webRequestBlocking` 在 WebSocket 握手前过滤 | 使用内建分级域名；拦截计数不可用，不等同于完整 EasyPrivacy WebSocket 匹配 |

Camoufox 启动时通过扩展目录内的自有本地页面验证扩展已就绪：仅匹配该页面的 content script 通过 `runtime.sendMessage` 确认后台已注册过滤规则，再写入供 Go 读取的 DOM 标记；失败时拒绝启动。该检查不发起网络请求，不创建监听、临时凭证或代理绕过。扩展位于档案之外的自有临时目录，在浏览器 context 关闭或启动失败时清理，不改写用户扩展或页面构造器。

BrowseForge Chromium 与 CloakBrowser 的当前接入范围是页面和 frame，不覆盖 worker WebSocket；Camoufox 临时扩展的 worker 行为尚未实测，不宣称已覆盖。上述机制不代表无法绕过的网络安全边界、完整遥测过滤或服务端账户关联防护。不同 provider 的接入与真实内核验收分别记录在[验证说明](verification.md)，不能从页面测试推断 worker 或所有内核已通过。

## 语言的不同层次

- **界面语言：** Envara 的界面选择，与环境无关；首次启动推荐系统语言并由用户确认。
- **浏览器：** 自动模式按网络地区推荐 locale，也可手动指定。请求语言、JavaScript 和 Intl 由对应内核接入处理。网站仍可按账户、Cookie、URL或服务端规则显示其他语言。
- **终端与 Claude：** 从宿主实际可用 locale 中选择有效 UTF-8 值，缺少请求 locale 时显示回退结果。LANG/LC_ALL 只传给自有子进程。
- **附加软件：** 接收同一有效子进程环境，但原生软件可能忽略语言提示。这不覆盖系统语言、字体或任意定位 API。

0.5.24 基线的地区测试使用明确标注的合成网络位置，核对传入坐标、语言与时区是否被内核消费；它不证明真实公网 IP、国家或住宅地址。真实出口需要另经指定代理检测。
