# 网络环境：一次确认，共同使用

创建或编辑网络环境时，先填写代理并验证实际出口；检测成功后显示 IP 地区和时区。用户可以确认推荐位置，或填写地址、粘贴 Google Maps 地点链接、输入坐标，再一起确认位置和时区并保存。

浏览器、终端和附加软件读取同一个已保存的网络环境，不再分别填写位置和时区。界面语言与网络环境的浏览器语言独立。

- 检测凭证只存在主进程内存，绑定完整代理配置，15 分钟过期；修改连接参数后需要重新检测。
- 同国家、同时区的出口 IP 轮换不覆盖用户确认的位置。实际国家或时区改变时，启动被拒绝，需回网络环境重新确认。
- 检测失败或托管内核退出时，不将已保存配置冒充当前检测结果。独立终端窗口也保留这一状态区别。
- 原有未确认位置的网络配置继续按旧规则使用，编辑后可以完成确认。

Google Maps 用于查看和选择地点。文本地址只保存为标签；明确地点链接或坐标才生成可供浏览器使用的定位覆盖。地图视角中心不被误当作地点坐标。IP 推荐位置保留城市级估算精度，不代表住宅地址或住宅 IP。

| 使用方式 | 已保存配置的使用范围 |
| --- | --- |
| 浏览器 | 受支持内核的时区、定位参数及已有隐私控制 |
| 终端 | 子进程时区、工作目录、工具配置；代理支持取决于命令行程序 |
| 附加软件 | 路由适配器及子进程上下文；任意桌面软件的 CoreLocation、硬件身份和加密遥测不能因此视为已覆盖 |

主机的时区、定位、DNS 和默认路由不因保存这份配置而改变。附加软件真实路由验收仍是独立门槛，不能以保存配置或 UI 测试替代。

验证记录见 `test-artifacts/network-flow-ui/result-20261009.json` 和 `failure-consumers-result-20261009.json`。这些是自有浏览器中的界面夹具验证，实际出口和原生分流标记明确为 false；后台测试另覆盖保存凭证、跨区拒绝、同区轮换和失败状态。
