# 网络环境：一次确认，共同使用

本文描述 Envara 1.1.1 的网络环境实现；发布制品验收与历史版本实测范围见[验证说明](verification.md)。创建或编辑网络环境时，填写代理并测量认证后的实际出口；成功后确认 IP 地区推荐的位置/时区，或选择手动位置。浏览器、终端和附加软件复用已保存上下文，不重复设置。

## 检测与保存

- 通过代理访问固定 HTTPS 地理服务，验证公网出口与 IANA 时区；不把代理入口地址或预设值当作成功检测。
- 确认凭证只在主进程内存中存在，绑定完整连接配置并限时有效；连接参数改变后重新检测。
- 同国家、同时区的出口 IP 轮换保留用户选择。实际国家或时区改变时拒绝启动，要求重新确认。
- 检测失败或托管核心退出时，不把保存的位置显示成当前检测成功；受管连接不自动改为直连。
- 旧的未确认位置配置保留原规则，直到用户明确编辑。

Google Maps 可辅助查看地点、粘贴地点链接或选择坐标。文本地址本身仅是标签；明确选择的地点坐标才用于受支持浏览器的定位覆盖，地图视角中心不当作地点。GeoIP 是地域估算，不证明住宅地址、住宅 IP 或某条街道。

## 附近参考与手动位置

认证出口检测成功且包含可用坐标后，Envara 经所选已验证路线向 Photon 查询一次附近参考位置，帮助理解地图上的周边地点。参考标签、参考坐标与测得的 IP 坐标分别保存；它不会提高 IP 定位精度，也不会替换浏览器定位或宿主位置。查询失败不会撤销已成功的出口检测，仍可确认 IP 推荐或改用手动位置。

附近参考随 IP 推荐一并确认保存。切换到手动模式后，以用户选择的地址和坐标为准，不再使用附近参考覆盖手动设置。

## 地址查询

在当前代理检测成功后，手动查询地址或地点，再从候选结果中选择坐标。查询凭证绑定刚检测的完整代理配置并限时有效；改动连接参数或凭证过期后需要重新检测。请求由主进程经所选已验证代理发送，不改用宿主直连，也不在输入文字时自动查询。

地址查询使用 Photon 公共服务与 OpenStreetMap 数据，最多返回五个候选；同一路线的相同查询使用短期内存缓存，并有请求频率限制。该公共服务允许适度使用，但不保证可用性；查询失败时可重试或手动填写坐标。服务条款见 [Photon demo server](https://github.com/komoot/photon#demo-server)，数据署名与许可见 [© OpenStreetMap contributors](https://www.openstreetmap.org/copyright)。

选择候选后，地址标签与坐标进入手动位置，仍需确认后保存。它不替代已测出口，不自动证明该坐标属于出口 IP，不证明住宅地址或住宅 IP。浏览器只接收其内核支持的定位覆盖；宿主定位不变。

## BrowseForge Chromium 地区

地区选择接入内核的完整预设目录，包括 249 个国家/地区代码与 27 个区域预设。有效的显式地区代码优先，其次使用已确认位置，最后使用已验证的出口地区；显式代码无效时要求修改，不静默换用另一个地区。没有精确区域匹配时使用支持的国家/地区代码，不从街道文本猜测城市，也不把不同来源的城市信息混合。

这些预设决定内核接收的地区参数，不保证当地代理质量、真实出口或网站判定。旧档案的身份和位置不会因为目录扩大而重新生成。

## 消费者边界

| 消费者 | 使用范围 |
| --- | --- |
| 浏览器 | provider 支持的时区、locale、定位与隐私参数 |
| 终端 | 子进程 TZ、有效 UTF-8 locale、代理与工具配置；托管回环路线在 macOS 拒绝直接公网连接和外部 DNS，仍允许本地开发服务及本地 IPC |
| 附加软件 | 通过已授权、满足运行条件的平台适配器出网；子进程配置不等于覆盖任意 CoreLocation、硬件或加密遥测 |

保存网络环境不修改宿主时区、定位、DNS或默认路由。附加软件安装/激活是另外的显式操作，不能用保存配置代替路由验收。普通终端的远端 HTTP(S) 上游及其他平台没有同等已验证围栏，不能称为受保护。

终端围栏不控制本地开发服务的后续联网；被允许的本地服务可能使用其自身网络。终端中保存的坐标只是共享上下文，不替换系统定位接口。WebRTC、网页定位与浏览器追踪规则须按实际浏览器分别验证，不能从浏览器推广为任意终端程序或附加软件的能力。

AnyTLS 由应用自有核心处理，保留 SNI、ALPN、TLS 指纹和 UDP 设置，默认证书校验开启。每个节点拥有独立认证回环入口，不需要另外配置 Clash；HTTP 入口不等于通用 UDP 代理。

附加软件使用的普通 HTTP、HTTPS、SOCKS5 上游接入同一自有 Mihomo 核心，提供独立认证回环入口与可核验的路线身份。HTTPS 支持单节点绑定，分组代理仍仅支持 HTTP、SOCKS5 和 AnyTLS；HTTPS 上游保持证书校验。普通终端直接使用远端 HTTP(S) 上游的既有边界不因此改变。具体准入和 UDP 限制见[附加软件路由](application-routing-options.md)。

HTTP/HTTPS 代理的 Basic 认证用户名不能包含冒号，密码允许包含冒号。上游返回 407 表示该次代理认证未获接受，不能据此推断所有 HTTP 代理不可用；仍需按具体节点验证凭证、认证策略与实际出口。
