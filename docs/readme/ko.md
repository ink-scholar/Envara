**브라우저를 열고, 명령을 실행하고, 데스크톱 앱으로 이어지는 작업. 하나의 환경에서 흐름을 이어 가세요.**

Envara는 네트워크 경로, 브라우저 프로필, 터미널 도구와 지원되는 데스크톱 앱을 한곳에 모은 오픈 소스 로컬 작업 공간입니다. 환경마다 설정과 데이터를 보관하므로 프로젝트, 계정이나 지역에 맞는 작업 환경을 만들고 한 화면에서 관리할 수 있습니다.

## Envara의 특징: 작업의 흐름을 하나로

브라우저에서 자료를 찾고, 터미널에서 코드를 쓰고, 데스크톱 앱에서 작업을 마무리합니다. 모두 같은 프로젝트를 위한 일이라면, 환경도 함께 이어져야 합니다. Envara는 확인된 네트워크 설정을 함께 사용하면서 브라우저 데이터, 도구 설정과 앱 데이터를 각각 보관합니다.

**네트워크를 한 번 선택하고 필요한 도구를 연결해 두면, 다음에는 하던 작업부터 이어 갈 수 있습니다.** 독립된 환경을 일상적인 작업 방식으로 만드는 것이 Envara의 핵심입니다.

### 🌐 환경마다, 나만의 브라우저

**CloakBrowser / Chromium, Camoufox / Firefox**, 실험 단계의 **BrowseForge Chromium** 중에서 선택하세요. 독립된 브라우저 데이터와 지속 세션, 환경 그룹, 검색, 설정 복제로 여러 작업 환경을 정리할 수 있습니다. 설정을 복제하면 새 환경이 만들어지며 기존 로그인 데이터는 원래 환경에 남습니다.

브라우저 지문 설정은 기본적으로 선택한 엔진이 관리하며, 고급 설정에서 기기, 언어와 시간대를 지정할 수도 있습니다. 확인 가능한 추적 차단 규칙을 함께 제공해 개인정보 보호 기능이 어떻게 작동하는지 살펴볼 수 있습니다. 지원 범위는 엔진마다 다릅니다. [브라우저 및 기기 설정](../browser-device-profiles.md)

### 🧭 네트워크, 위치와 시간대는 한 번 설정하고 함께 사용

**HTTP, HTTPS, SOCKS5와 AnyTLS**를 지원합니다. AnyTLS는 앱에 포함된 Envara 관리 프록시 코어를 사용하므로 Clash를 따로 설정할 필요가 없습니다.

네트워크 환경을 만들 때 **프록시 인증을 거친 실제 외부 IP**를 확인한 뒤 지역과 시간대를 확정합니다. 브라우저, 터미널과 지원되는 연결 앱은 이 설정을 함께 사용합니다. 모의 위치가 필요하면 Google Maps로 좌표를 선택할 수 있으며, 측정한 네트워크 경로와 설정한 위치는 구분해 표시합니다. 환경 설정은 호스트 시스템의 시간대를 바꾸지 않습니다. [네트워크 환경](../network-context.md)

### ⌨️ 터미널에도 독립된 작업 환경

새 세션을 만들 때 **네트워크, 링크를 열 브라우저와 프로젝트 폴더**를 선택합니다. 설정과 기록은 환경마다 보관합니다. 실제 PTY, 여러 세션, 높이 조절 패널, 작업 공간으로 확장하기, 독립 창까지 제공해 명령줄도 작업 공간의 편리한 일부가 됩니다.

터미널을 복제하면 같은 설정을 사용하는 새로운 대기 프로세스가 생성됩니다. 패널을 닫아도 세션으로 돌아와 작업을 이어 갈 수 있습니다. 지원되는 macOS 관리형 루프백 경로에는 네트워크 격리 경계를 적용해, 프록시를 지원하지 않는 프로그램은 연결에 실패하도록 하여 조용히 직접 연결로 우회하는 일을 막습니다. 프로젝트 폴더는 원래 위치에 있으므로 기존 도구 체인을 계속 활용할 수 있습니다.

### 🧩 데스크톱 앱도 같은 작업 흐름으로

지원되는 **Chromium / Electron 앱**에 환경과 링크 브라우저를 지정하고 시작, 중지와 앱 데이터를 한곳에서 관리할 수 있습니다. Envara는 대상 앱의 식별 정보, 호환성, 기존 실행 인스턴스와 네이티브 라우팅 구성 요소를 확인하며, 조건이 충족된 경우에만 시작을 허용합니다.

중지, 연결 해제나 Envara 종료 후에도 로그인 정보와 오프라인 데이터를 보관해 다음에 이어서 사용할 수 있습니다. 정리가 필요할 때 명시적으로 삭제를 선택하면 됩니다. 네이티브 라우팅에는 시스템 승인이 필요하며, 엔진을 지원한다는 것이 모든 앱의 검증 완료를 뜻하지는 않습니다. [연결된 앱의 지원 범위](../application-routing-options.md)

### 🔗 명령줄에서 로그인 페이지까지, 같은 환경으로

환경의 링크 브라우저를 지정하면 터미널에서 여는 웹페이지를 해당 환경으로 연결할 수 있습니다. macOS 시스템 링크 라우팅은 관리되는 앱이 시스템에 넘기는 링크도 처리합니다. 환경과 관계없는 링크는 기존 기본 브라우저로 전달됩니다.

시스템 링크 라우팅은 macOS 대화상자에서 직접 승인해야 하며 언제든 끌 수 있습니다. 시스템 브라우저를 명시적으로 선택하면 링크가 환경 밖에서 열린다는 안내가 표시됩니다.

### 🤖 AI와 자동화 도구를 위한 정돈된 작업 공간

브라우저 백엔드는 **REST, MCP와 Playwright** 인터페이스를 제공합니다. 페이지 조작, 양식, Cookie와 스크린샷 등 브라우저 자동화에 활용할 수 있습니다. 지원 범위는 [기능 표](../capability-matrix.md)를 참고하세요.

Claude Code는 여러 통합 기능 중 하나입니다. 환경마다 **수정하지 않은 공식 CLI**를 독립적으로 설치하고, 이름을 지정한 로그인 프로필을 보관합니다. 세션 단위 MCP broker를 통해 선택한 환경의 브라우저와 연결합니다. 먼저 shell에 진입한 뒤 직접 `claude`를 실행하며, 모델, 세션 재개와 권한 옵션은 사용자가 결정합니다. [Claude Code 세션](../claude-code-sessions.md)

### 📦 옮길 때는, 필요한 데이터만

브라우저, 터미널과 연결된 앱의 각 화면에서 **비밀번호로 암호화해 내보내기**를 제공합니다. 터미널 내보내기에는 선택한 Claude 로그인 프로필과 공용 shell 설정·기록이 포함됩니다. 가져오기는 새 환경을 만들며 기존 작업 공간을 보존합니다.

프로그램 본체, 캐시, 임시 파일과 Keychain은 포함하지 않습니다. 다른 기기로 옮기면 일부 계정에 다시 로그인해야 할 수 있습니다.

### 🗂️ 일상적인 관리는 간결하게

어두운 테마의 3열 작업 공간에 환경, 네트워크, 브라우저, 터미널, 연결된 앱과 실행 상태를 보기 쉽게 배치했습니다. 자주 쓰는 작업은 바로 접근하고 세부 설정은 고급 옵션에서 조절할 수 있습니다. 9개 인터페이스 언어 중 익숙한 언어로 시작하세요.

## 다운로드 및 설치

[GitHub Releases](https://github.com/ink-scholar/Envara/releases/latest)에서 **macOS Apple Silicon(arm64)**용 DMG 또는 ZIP을 다운로드하세요. DMG를 열고 Envara를 ‘응용 프로그램’ 폴더로 드래그하면 됩니다. 체크섬 파일과 버전 설명은 Release에 함께 제공됩니다.

**현재 macOS 배포 파일은 Apple Developer ID 서명과 공증을 받지 않았습니다.** 처음 열 때 macOS 보안 검사로 실행이 차단될 수 있으므로 이 저장소에서 다운로드했는지 확인하고 체크섬을 대조하세요. Envara는 시스템 보안 검사를 자동으로 끄지 않습니다. 연결된 앱의 시스템 라우팅 구성 요소에는 별도의 관리자 승인이 필요하며, 브라우저나 일반 작업 공간을 시작할 때 자동으로 설치되지 않습니다.

| 플랫폼 | 이번 배포 범위 |
| --- | --- |
| macOS Apple Silicon | DMG, ZIP 및 SHA-256 체크섬 파일 제공 |
| macOS Intel | 소스 코드는 유지하지만 검증된 배포 파일은 제공하지 않음 |
| Windows / Linux | 관련 소스 코드는 유지하지만 이번에는 배포 파일을 공개하지 않음. 실제 기기 검증 범위는 기능 표 참고 |

브라우저 엔진은 사용자가 앱 내 설치 기능을 통해 설치하며, 각 엔진의 라이선스가 적용됩니다. 데스크톱 실행에 필요한 의존성은 앱에 포함되어 있어 Node.js나 Go를 별도로 설치할 필요가 없습니다.

## 격리와 개인정보 보호에 관하여

Envara는 제어 가능한 네트워크, 분리된 데이터와 확인 가능한 개인정보 보호 기능을 중요하게 생각합니다. 실제 지원 범위에 맞게 사용할 수 있도록 다음 한계를 명확히 안내합니다.

- 설정과 데이터 분리는 별도의 운영체제 사용자, Keychain이나 가상 하드웨어를 제공하지 않습니다. 브라우저 지문 설정은 네이티브 앱의 하드웨어 식별 정보를 바꾸지 않습니다.
- 지원되는 macOS 터미널 경로에는 네트워크 격리 경계를 적용합니다. 이 경계가 아직 구현되지 않은 플랫폼과 경로는 강제로 격리된 것으로 볼 수 없습니다. 자세한 범위는 [기능 표](../capability-matrix.md)를 참고하세요.
- 연결된 앱에 외부 네트워크 격리 경계를 적용할 때는 Chromium/Electron의 내부 샌드박스가 비활성화됩니다. 네이티브 구성 요소 상태, 지원 엔진과 실제 검증 범위를 구분해 설명하며, ‘인식 가능’을 ‘모든 앱 검증 완료’로 간주하지 않습니다.
- 내보내기에는 Keychain, 프로그램 본체, 캐시나 임시 파일이 포함되지 않습니다. 다른 기기에서는 일부 계정에 다시 로그인해야 할 수 있습니다. 같은 기기에서 복원에 성공해도 다른 기기에서 로그인 상태가 유지된다고 보장하지 않습니다.
- 추적 차단은 구현된 규칙과 엔진이 지원하는 제어 범위에 한정됩니다. 네트워크, 계정과 설정 분리는 서비스 제한 회피를 보장하지 않으며 모든 추적을 제거하지도 않습니다.

## 소스 코드로 개발

Node.js 24 LTS(또는 22.12+), npm, Go 1.25와 대상 플랫폼의 빌드 도구가 필요합니다. macOS 네이티브 구성 요소에는 Xcode Command Line Tools가 필요합니다.

```bash
npm ci
npm run desktop
```

초기 준비 과정에서 고정 버전의 빌드 의존성을 다운로드합니다. 개발용 미리 보기와 검사는 다음 명령으로 실행할 수 있습니다.

```bash
npm run dev
npm test
npm run build
npm run test:sites
```

Web 미리 보기는 인터페이스 개발용입니다. 실제 브라우저, PTY와 시스템 라우팅에는 데스크톱 앱이 필요합니다. 빌드와 배포 방법은 [기여 안내](../../CONTRIBUTING.md)와 [릴리스 절차](../releasing.md)를 참고하세요. GitHub 자동 빌드·릴리스 워크플로는 비활성 상태를 유지하며, 소스를 push해도 빌드가 실행되지 않습니다.
