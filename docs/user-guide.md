# Envara 使用指南

给一个项目或账号建立境舱，让浏览器、终端和支持的桌面应用共享确认过的网络，各自保留需要继续使用的数据。

[返回首页](../README.md) · [下载](https://github.com/ink-scholar/Envara/releases/latest) · [功能与平台边界](capability-matrix.md) · [支持项目](SUPPORT.md)

**快速开始：** 安装 Envara → 添加并检测网络出口 → 创建环境 → 安装浏览器内核并启动 → 按需打开终端、Claude Code 或附加软件。

## 安装与界面

1. 从 [Releases](https://github.com/ink-scholar/Envara/releases/latest) 下载 **macOS Apple Silicon（arm64）** 的 DMG 或 ZIP；校验文件随版本提供。
2. 打开 DMG，将 Envara 拖入“应用程序”；ZIP 解压后同样放入“应用程序”。当前制品没有 Apple Developer ID 签名或公证，首次打开可能受到 macOS 安全检查，请先核对下载来源与校验值。
3. 首次启动时确认界面语言。支持简体中文、繁體中文、English、日本語、한국어、Español、Français、Deutsch 和 Português (Brasil)，默认推荐系统语言。
4. 在左下角 **设置** 中选择浅色、深色或跟随系统；语言和外观选择会保存。

安装包自带桌面运行依赖，不需要另装 Node.js 或 Go。浏览器内核按需从应用内安装；附加软件的系统网络组件也由你明确选择安装。

左侧依次是 **环境、网络出口、浏览器、终端、附加软件、运行监控**；中间处理当前工作，右侧查看所选环境。界面语言与浏览器语言独立，外观、环境时区和位置设置不会改变宿主系统的对应设置。

## 网络出口

### 添加并确认一条网络

1. 打开 **网络出口**，添加节点名称、协议、服务器、端口，以及服务商要求的认证信息。
2. 执行出口检测，等待显示实际公网 IP、地区和时区。这里测量的是**经过代理认证后的出口**，不是代理服务器入口地址。
3. 确认 IP 推荐的位置与时区，或切换到手动位置后再确认，最后保存。
4. 在环境中选择这个出口。浏览器、终端和支持的附加软件复用已保存的网络上下文。

| 协议 | 使用说明 |
| --- | --- |
| HTTP / HTTPS | 填写服务器、端口和认证信息；HTTPS 校验证书。Basic 认证用户名不能包含冒号，密码可以包含冒号 |
| SOCKS5 | 按节点要求填写认证信息；实际可用能力由节点与使用它的工作流共同决定 |
| AnyTLS | 保留节点的 SNI、ALPN、TLS 指纹及 UDP 设置，默认证书校验开启；使用 Envara 自带的托管核心，无需另装 Clash |

同一网络可以供多个环境使用；环境分组便于筛选和批量管理。已有分组默认或强制网络策略会在环境选择中体现。**HTTPS 目前用于环境直接绑定的单节点；分组代理支持 HTTP、SOCKS5 和 AnyTLS。**

修改连接参数后需重新检测。国家或时区变化时，按提示重新确认；旧配置会保留到你明确更新。托管路线不可用时不会悄悄改成直连。“本机网络”则是你明确选择的宿主网络，不属于代理保护路线。

### 自动附近地址与手动定位

成功检测且有可用坐标时，Envara 会经所选路线查询一个附近街道或地点作为参考。附近地址是帮助理解地图的标签，**不会提高 IP 定位精度，也不证明住宅 IP 或真实街道地址**。

需要手动位置时，可查询地点并选择候选、使用 Google Maps 辅助选择，或填写坐标；确认后保存。手动位置优先于附近参考，测得出口与所选模拟位置仍分别保留。只有支持定位覆盖的浏览器会使用该坐标，宿主和任意原生软件的系统定位不会随之改变。

地址服务暂不可用时，仍可确认已测出口或手动填写坐标。详细规则见[网络环境](network-context.md)。

## 环境与浏览器

### 创建并开始浏览

1. 在 **环境 → 新建环境** 填写名称，选择网络出口与浏览器内核。
2. 一般保留默认指纹即可。需要分组、隐私模式、设备模板、浏览器语言、窗口大小或启动页面时，展开 **高级设置**。
3. 在 **浏览器** 页面按需安装所选内核，显示就绪后启动。
4. 下次继续使用同一环境即可保留其资料；运行中可打开已有窗口，结束时使用停止操作。

| 内核 | 适合的选择 |
| --- | --- |
| CloakBrowser / Chromium | Chromium 工作流 |
| Camoufox / Firefox | Firefox 工作流，使用其完整设备模板 |
| BrowseForge Chromium Alpha | 想尝试其 Chromium 指纹与地区能力；该内核仍标为实验性 |

三个内核的具体能力不同；界面会禁用当前平台或内核不支持的选项。创建后保留内核选择，需要不同内核时创建另一个环境。

### 身份如何保留

| 操作 | 身份与资料的变化 |
| --- | --- |
| 新建环境 | 生成并保存相容的随机身份配置 |
| 关闭后重开 | 继续使用已保存身份与浏览资料 |
| 克隆环境 | 创建新身份，保留显式设备约束；不复制原浏览器登录资料 |
| 导入 | 保留导出的身份配置；加密资料包另恢复其包含的数据 |

已有固定、自定义或导入配置不会被自动重新随机。旧 BrowseForge 零种子档案若曾依赖原环境 ID，导入新 ID 后存在身份派生差异；正常新生成身份与已保存的非零种子适用上述保留规则。

**隐私防护** 提供标准、严格和停用：标准拦截已知第三方追踪；严格增加标签管理器、错误上报和广告网络规则。网站功能受影响时，可调整该环境的设置。规则覆盖的 HTTP(S)、页面/frame WS/WSS 范围随内核而异，不能等同于所有追踪均被移除。

标准和严格模式都为已核实的付款服务保留有限兼容规则，包括 Stripe 的付款与风控服务、Braintree/PayPal 的支付 SDK 日志，以及 Adyen 的指定结账分析接口。例外限定 HTTPS、标准端口及列明的主机或路径，其他追踪规则继续生效；具体范围与官方依据见[付款兼容规则](../third_party/browseforge/internal/browser/privacy_payment.go)。这不会改变代理、第三方 Cookie 或证书验证设置。付款页面出现代理隧道连接失败时，仍需排查所选网络是否能连接支付服务。

环境页面支持搜索、分组筛选、批量启动/停止和移动分组。**清空浏览数据** 会清除 Cookie、缓存与历史，保留环境配置；**删除环境** 是删除操作，执行前先导出所需资料。

高级用户可通过后台 **REST、MCP、Playwright** 接口进行页面、标签、表单、Cookie、截图等自动化；固定后端还保留 YAML 工作流能力，当前没有桌面可视化工作流编辑器。接口覆盖和设备细节见[功能矩阵](capability-matrix.md)与[浏览器设备设置](browser-device-profiles.md)。

## 终端

1. 打开 **终端 → 新建会话**，选择普通终端。
2. 选择网络出口、链接浏览器，再通过文件夹选择器指定工作目录。
3. 打开终端，像平时一样运行命令。配置与历史按环境保存，项目文件仍位于你选择的原目录。

| 操作 | 结果 |
| --- | --- |
| 拖动顶部边缘、放大或还原 | 调整终端在工作区中的空间 |
| 独立终端窗口 | 在另一个窗口查看该环境终端 |
| 收起面板、关闭独立窗口 | 保留会话和正在运行的进程 |
| 复制终端 | 在相同上下文中创建新的空闲进程，不重放命令 |
| 关闭会话 | 结束该会话进程 |

macOS 的托管回环路线使用网络围栏：不支持代理的程序连接失败，不能自行走直接公网。终端底部会显示实际网络模式；普通终端直接使用远端 HTTP(S) 上游时，没有同等已验证围栏。本地开发服务和 IPC 仍可访问，这些本地服务自身的后续联网不由该围栏控制。

工作目录是实际文件夹，不是文件系统沙箱。切换环境不会复制或隔离项目文件。

## Claude Code

如果你因“Claude 防封”而来，Envara 提供的是**减少环境混用、控制网络与隐私的具体工具**：固定经过验证的路线、分开的登录档案、绑定环境浏览器、持久浏览器身份，以及限定接口的设备标识读取限制。账号是否受限仍由服务方判断，Envara 不承诺免封或完整匿名。

### 安装、登录与启动

1. 先准备已确认出口的环境及浏览器。
2. 在 **终端 → 新建会话 → Claude Code** 中选择网络、浏览器、登录档案和工作目录。
3. 首次使用选择 **下载独立安装（推荐）**，经环境路线下载、核验并安装官方程序；也可选择 **从本机 Claude 初始化**，只复制支持的原生程序，不复制本机账号与配置。
4. 打开后先进入 shell。输入 `claude`，按官方 CLI 的提示登录和使用；退出 Claude 后回到 shell。

每个环境保存自己的**原样官方 CLI**。有效安装会复用，不会静默改用本机程序；安装取消或失败保留已有账户数据。模型、恢复会话及权限参数由你自己决定，不会自动开启权限绕过。

### 登录档案与更新

在新建会话中可先创建命名档案，之后通过 **管理档案** 改名或确认删除。档案名称用于区分用途，不表示已登录状态；网页账号与 CLI 登录也各自独立。

改名保留资料；删除仅移除所选档案的配置和历史。默认档案可改名，不能单独删除。使用该档案的终端需先点击 **关闭会话** 结束进程，仅关闭窗口不够。复制终端会沿用所选档案，新建空闲 shell。

后台自动更新关闭。需要时在该环境中显式运行 `claude update`，新版本用于该环境的下一次调用，不改动宿主 Claude，也不替换已经运行中的进程。

### 浏览器、网络与隐私

- **绑定浏览器：** 专用会话的网页链接与 `envara_browser` 工具固定使用所选环境浏览器，支持导航、查看页面、点击、输入、截图及标签操作；绑定失效时拒绝使用，不替换为系统浏览器。
- **绑定网络：** 专用会话要求已验证的托管回环路线与 macOS 网络围栏；网络核心退出时结束关联 Claude 进程并撤销浏览器能力。
- **官方隐私开关：** 标准模式设置 `DO_NOT_TRACK`、关闭遥测和错误上报；严格模式再关闭非必要流量。其效力依赖官方 CLI，可能影响可选功能，正常模型和账号请求仍会发生。
- **设备读取限制：** 会话设置仅在已启用时显示序列号与 UUID 读取限制；只覆盖已验证接口，不创建虚拟硬件身份。

专用启动不加载项目级 MCP/settings 或 Chrome 集成来替换受管绑定；环境内用户设置仍可使用，冲突的认证、服务商或路由配置会在启动前提示。外层网络围栏下关闭 Claude 嵌套沙箱，常规权限提示仍由你控制。

真实账号登录、令牌刷新、模型调用和模型主动调用工具需要分别验证，不能从“终端已打开”推断成功。更多细节见 [Claude Code 会话](claude-code-sessions.md)。

## 附加软件

把支持的 Chromium / Electron 桌面应用加入境舱，使用该环境的网络与独立应用资料。是否可启动以界面的身份、引擎及路由检查为准，不是所有桌面软件都支持。

1. 在 **附加软件** 选择添加，依次选择网络分组、搜索本地软件、选择链接浏览器。
2. 首次按界面提示 **安装网络组件**；旧组件不匹配时使用 **更新网络组件**。授权通过 macOS 自身提示完成。仅查看状态不会安装组件或更改网络。
3. 先自行关闭同一软件的原版或已有实例，再点击 **启动**。Envara 不会替你结束无关会话。
4. 关闭窗口后程序可能仍在运行；使用 **打开窗口** 或程序坞图标继续。
5. 点击 **停止** 结束受管进程及所属路由。切换网络或重新启动前，等清理完成；若显示 **重试清理**，先完成清理再继续。

同一软件身份一次绑定一个环境、运行一个受管实例。应用的用户数据、Home、缓存、临时目录与扩展目录按环境分开；VS Code 也使用独立共享数据和扩展目录。

**停止、移除绑定、退出 Envara 都保留登录与离线资料。** 想删除时，在 **应用数据** 中选中对应项并确认；外部项目文件与软件本体不在该删除范围。日志同时保留首次启动错误和后续清理错误，可展开查看或导出诊断。

macOS 路线需要原生网络组件与外层 Seatbelt 围栏。Chromium/Electron 运行时使用 `--no-sandbox`，会关闭应用自身的 Chromium 内层沙箱；外层网络围栏不能代替同一种内部进程隔离。当前 PF 路线阻断 UDP，节点支持 UDP 也不代表附加软件能使用它。

独立资料目录不会替换 macOS 用户、Keychain、硬件身份或系统定位，也不会自动给软件加入浏览器指纹与跟踪规则。支持范围与已测场景见[附加软件路由](application-routing-options.md)。

## 打开链接

默认使用环境自己的浏览器，也可选择同一网络下的另一个已保存浏览器。普通工作流的已保存选择不存在时回到环境浏览器；专用 Claude 会话的固定绑定失效则拒绝操作。

**设置 → 打开链接 → 境舱内打开链接** 默认开启。终端链接通过境舱内部通道打开，不需要更改系统默认浏览器；首次启动不会申请该变更。

**附加应用链接接管** 是独立的可选功能。需要接收附加应用交给 macOS 的登录等链接时，点击 **启用系统链接接管**，再由你接受 macOS 的默认浏览器变更提示。启用后，受管理应用的链接交给环境浏览器，无关应用的链接仍交给原默认浏览器。点击 **恢复原默认浏览器** 可以撤销系统接管，同时保留境舱内部的链接方式。

主动选择 **系统默认浏览器** 会让链接离开环境，界面会说明这一点。关闭普通链接开关不改变 Claude 专用会话的浏览器绑定。

## 备份与迁移

### 导出选中的资料

先停止要导出的浏览器、终端或软件，再到它自己的页面选择导出，设置并确认加密密码，保存文件。

| 入口 | 导出的内容 |
| --- | --- |
| 浏览器 → 导出浏览器 | 该浏览器配置与可迁移网站资料 |
| 终端 → 导出终端 | 共享 shell 配置、历史，以及你选择的一个 Claude 登录档案 |
| 附加软件 → 导出软件 | 该软件在此环境内的设置与应用数据，包括应保留的离线内容 |

程序本体、缓存、临时文件、宿主凭据与 Keychain 不导出，运行时代理入口凭据也不写入资料包。妥善保管密码；复制文件不保证另一台机器继续登录。

### 导入并恢复

1. 在 **环境 → 导入** 选择文件；加密文件按提示输入密码。
2. 明确映射到本机已有网络出口。导入创建**新环境**，不覆盖原环境，也不把敏感代理凭据当作公共配置分享。
3. 按提示准备浏览器内核或本地软件。部分资料需先启动并停止一次以生成目标目录，再启动生效；以导入后的提示为准。

旧整环境导出文件仍兼容。应用尚未绑定或同一软件已有绑定时，先处理绑定再恢复。部分登录需要重新认证；尤其是依赖 Keychain 或设备状态的账号，不能承诺跨机器直接使用。

普通停止操作保留数据；**清空浏览数据、删除登录档案、删除应用数据、删除环境** 才是明确删除入口。不可恢复的操作前先导出所需内容。

## 运行监控与常见问题

**运行监控** 汇总正在启动、运行、停止中的浏览器、终端和附加软件，并展示近期运行记录。点击 **查看** 返回相应页面；计数和状态说明当前进程生命周期，不等于账号、网络与全部隐私机制已验证。

| 遇到的情况 | 下一步 |
| --- | --- |
| 未检测到出口 / 代理认证失败 | 检查协议、端口和凭据后重新检测；HTTP 407 表示该次代理认证未获接受 |
| 出口国家或时区改变 | 在网络出口重新检测并确认位置，再启动工作流 |
| 浏览器无法启动 | 检查内核是否安装、当前平台是否支持，以及所选网络的检测状态 |
| Claude 不能启动 | 按提示检查官方安装、登录档案、已验证网络和浏览器绑定；配置冲突需在对应档案内处理 |
| 软件提示已有实例 | 自行关闭那个软件的现有会话，再重试；不要把已有个人会话当作受管实例 |
| 软件启动失败并提示清理未确认 | 保留首次错误，使用重试清理；清理完成后再重启，必要时导出诊断 |
| 关掉终端窗口后命令还在运行 | 这是保留会话的设计；要退出进程请点击关闭会话 |
| 导入后仍要登录 | 依赖 Keychain、设备或服务端会话的账号可能需要重新认证 |

反馈问题时附上 Envara 版本、系统版本、错误码和可复现步骤；不要公开账号凭据、节点密码、私人地址或含敏感内容的截图。

## 能力边界

当前发布制品面向 **macOS Apple Silicon**；Windows、macOS Intel 与 Linux 的源码或构建入口不等于已完成实机支持。Envara 是本机单用户工作区，当前没有云同步、成员邀请或团队权限管理。

浏览器身份、独立目录和受管网络不构成虚拟机、独立系统用户或完整匿名。指纹表面、WebRTC、字体、GPU 与各应用的路由能力需要分别检查；不承诺所有检测器、全部追踪或服务端账号规则都失效。
