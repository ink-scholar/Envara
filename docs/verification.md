## 验证范围

代理的原生验证覆盖本地认证 HTTP 代理；HTTPS、SOCKS5 和外部供应商出口仍需单独测试。界面的代理检查验证 TCP 端口连通性，不验证认证或出口 IP。

没有对所有指纹字段、检测网站、设备画像或硬件组合进行验收。这些结果不构成“无法检测”、自动通过验证码或完整模拟任意设备的保证。

复核基础检查时先生成构建文件：

```bash
npm test
npm run build
npm run test:sites
```

原生验证脚本 `npm run test:smoke` 会使用独立测试工作区并可能从官方渠道安装测试内核；需要联网和可显示桌面窗口的环境。最终版本与平台验收完成后，应同步更新本记录和 README 的支持表。
