# 工作区管理与维护

这些工具沿用环境的目录、登录档案和网络绑定。查看状态不会自动升级软件、修改宿主机设置或重新登录。

## 终端与工作组合

- 在终端的已保存入口中，按名称、目录或登录档案搜索；置顶与上下移动会保存，重新打开后保留顺序。排序不改变已运行的进程。
- 点击终端标签切换会话。复制会话会创建相同环境、工作目录及登录档案下的新空闲进程，不回放命令、不复制运行状态。
- 当前 Claude 会话的设置可以直接打开登录档案管理，并查看使用该档案的会话。档案名称不是登录状态判断。
- 将图片或文件粘贴、拖入支持的本地终端，会在当前环境的附件目录保存副本并插入引用后的路径，不自动回车。处理期间暂停后续输入；切换或取消会停止未提交的传输。已提交的附件保留。SSH 和无法确认的前台程序不接受本地附件路径。
- 环境页面的“工作组合”保存最多八个已保存终端及可选的本环境浏览器。目录、档案或网络绑定失效时拒绝启动。每次打开都新建空闲终端；若中途失败，已创建的会话保留并明确报告部分完成。

## 运行核验与诊断

运行监控支持搜索记录和只看错误。“运行实测核验”由用户手动触发，对已有可信路由的运行中 Chromium 浏览器新建后台临时页面，读取实际语言、时区，并通过该浏览器查询出口。检查结束后按精确目标标识关闭本次创建的页面。Camoufox 暂无已实现的安全后台页面能力，核验保持未观测。结果带时间和作用范围；配置、实例或网络改变后失效，五分钟后标记过期。

终端显示启动时传入的设置。核验不会往用户终端输入命令，因此当前 shell、子进程和 SSH 远端的实际出口、语言仍标记为未观测。浏览器一次页面的测量也不能证明所有应用都经过相同路线。

设置中的支持诊断导出为本地 JSON，包含启动、运行耗时、已有网络检查、恢复状态和附加软件诊断的白名单字段。每部分注明成功、缺失或采集失败，不为导出重新探测网络。包中不包含令牌、节点凭据、私有地址、设备标识、命令、终端输出、对话或用户路径；导出不会上传。

## 网站 Cookie

在浏览器页面展开所选环境的网站 Cookie 面板，手动刷新运行中浏览器的 Cookie 元数据。面板不显示 Cookie 内容，按准确存储域清理，并在确认时说明该域所有分区的范围；共享域也可能影响其子网站。搜索不会缩小确认后的整域删除范围。

Chromium 两种内核使用精确 CDP 删除，不采用“清空全部再补回其他域”。Camoufox 当前提供只读查看，分区信息及安全定点删除尚不受支持。面板不清理浏览历史、Local Storage 或其他离线存储。运行中的网站可能重新写入 Cookie。

## 组件与缓存

组件面板区分当前应用版本、安装记录、随包版本及未观测的运行版本，并列出相关会话和更新影响。安装、系统授权及兼容性检查沿用现有手动流程。Claude 更新只提供环境终端入口和手动操作说明，不替用户执行命令。

缓存维护仅处理已知、可重建的浏览器缓存目录；Cookie、历史记录、登录档案和离线内容不在范围内。检查库存只读；实际移出和恢复前重新确认文件、环境空闲状态，并在浏览器后端持有维护许可，阻止同环境启动及修改资料目录。无法确认状态时拒绝操作。

选中的缓存先移到私有恢复批次，恢复副本仍占用磁盘。恢复遇到新缓存时保留新缓存与恢复副本，不覆盖。永久删除只作用于用户二次确认的恢复批次。附加软件的特权数据不纳入此浏览器缓存工具。

缓存写入与删除要求已实现的文件所有权校验。当前 macOS 支持此流程；Windows 缺少等价 ACL 校验时只提供只读库存，禁止移出、恢复和永久删除。Linux 使用 POSIX 校验路径，仍需对应平台验收。

维护许可不自动超时放行；释放无法确认时保留拒绝启动状态，避免在文件操作未完成时使用资料。应用退出会等待本次维护收尾。该机制用于协调本应用及其浏览器后端，不等同于针对同一系统用户恶意进程的完整文件系统隔离。
